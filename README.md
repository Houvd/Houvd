# Hi, I'm Giuseppe

I build interactive audio software and multimedia systems, with a focus on creative coding, real-time interaction, and cross-platform integration.

My work spans tools and workflows such as JUCE, Flutter, Processing, SuperCollider, MIDI, and OSC.

## Selected projects

### Carps
Interactive audio application for gesture-controlled sound synthesis built with JUCE, SuperCollider, and Processing.  
**Contribution:** JUCE development, integration with SuperCollider and Processing, and co-design of the application.

### Primavera
Audioreactive generative art installation combining AI-generated visuals with OSC/MIDI-based audio communication.  
**Contribution:** development of the audio communication layer and OSC/MIDI integration.

### MAE-Capstone
Scalable GUI for 3D audio control and MIDI-based interaction across different hardware setups.  
**Contribution:** application development, GUI implementation, and contribution to the MIDI interaction workflow.

### DreamLink
Flutter mobile application with Spotify integration and audio-focused features.  
**Contribution:** co-development of the app, focusing on the audio section and Spotify integration.
